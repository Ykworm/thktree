## 实现内容


### 2. 设计 token 体系

新增 `lib/ui/features/settings/tts_tokens.dart`，4 类：

- **TtsSpacing** — player 页内边距（24/12）、section gap 20、行高 1.7、mini bar padding（20/14，14+14 居中）、message bubble 按钮 gap、voice 列表 padding
- **TtsDimensions** — mini bar 总高 68、播放按钮 40 圆形（iconSize 18，半径 20）、滑块、波形条（5×8，max 48）、脉冲点 8
- **TtsMotion** — 按钮 transition 200ms、波形 tick 100ms、脉冲环 1800ms、glow shift 2400ms、回顶 300ms easeOut
- **TtsColors** — 复用 AppColors / CupertinoColors.systemBlue / champagneGold（脉冲点）

### 3. UI 行为

- **MessageBubble**：assistant 消息底部新增播放按钮（复制按钮右侧）。点击 push 全屏 TtsPlayerScreen；playing 时按钮变 stop.fill 配 systemBlue
- **TtsPlayerScreen**：nav 标题 "朗读" + 文本可滚动区 + 语速滑块（slow/fast 图标）+ 大播放按钮（带 2 环 pulse_rings）+ 5-bar 波形（仅 speaking 时动）+ 语音设置入口
- **TtsSettingsScreen**：Apple 系统语音（只读）+ 声音列表（中文优先 + "其他" 兜底），选中自动试听
- **SettingsScreen 入口**：新增 "语音设置" ThkListSection，点击跳 TtsSettingsScreen

### 4. 持久化

- **声音**：扩展 `AppSettings.ttsVoiceId` + `SettingsStore.saveTtsVoiceId`（用 flutter_secure_storage）
- **语速**：不持久化，每次 player 打开默认 0.5（per design doc §1.2）

### 5. 动效细节

- 全部受 `prefersReducedMotion` 约束（v1 在 [TtsWaveform] 等组件内隐式接受 MediaQuery 派发；v2 见 §11）
- 动效仅在 `isSpeaking == true` 启动，speaking 结束立即停（`AnimationController.stop()` + 立即归零）
- 每个动效子树独立 `RepaintBoundary`，避免 player 页整体重绘

### 6. 国际化

新增 16 个 l10n key（zh + en 各 16）：

- 播放器：`ttsPlay` / `ttsPlayerPlay` / `ttsPlayerStop` / `ttsRate` / `ttsSlow` / `ttsFast` / `ttsBackToTop`
- 设置：`ttsVoice` / `ttsVoiceSettings` / `ttsVoiceSettingsSubtitle` / `ttsEngine` / `ttsAppleSystem` / `ttsTestPlay`
- 通用：`ttsStop` / `ttsNoVoicesAvailable` / `ttsIosOnly`

## 已知问题

1. **Xcode project 未自动注册 TtsPlugin.swift** — 需要用户手动拖入 Runner target，或用 `xcodeproj` gem 改 `project.pbxproj`
2. **未跑 iOS XCTest** — MVP 阶段不强制；v2 路线图里有
3. **iOS 18+ 隐私审核** — 当前不需要权限（仅 TTS 输出），但若后续加听写/识别需 Info.plist 加 `NSSpeechRecognitionUsageDescription`

## UI 迭代（同日）

在 v1 基础上进行的 UI 优化，参考小宇宙播客 App 设计。

### 布局重构

- **控制面板**：从 Column 子节点改为 `Positioned` 叠在底部，文本区 `Positioned.fill` 铺满全屏
- **毛玻璃效果**：`BackdropFilter` 包裹 `ClipRRect`（修正层级），alpha 0.85 → 0.65 → **0.35**（更透，背后 champagne gold 渐变明显可见）
- **Mini bar 布局**：控制面板改为 `Row`，播放按钮在左、速度标签在右
- **移除浮按钮**：`TtsBackToTopButton` 移除，改为双击导航栏标题回到顶部

### 播放按钮

| 项目 | v1 | 迭代后 |
|------|-----|--------|
| 尺寸 | 80dp | 40dp |
| 图标（空闲） | `speaker.wave.2` | `AppIcons.ttsPlay`（`sf_play_fill`，三角形） |
| 图标（播放中） | `stop.fill` | `AppIcons.ttsPause`（`sf_pause_fill`，两竖） |

### 语速

### 导航栏

- `ThkNavBar.inline` 新增 `onTitleDoubleTap` 参数，用于 TTS 播放器双击标题回到顶部

### Markdown 渲染
