## 4. 风险与权衡

| 风险 | 应对 |
|------|------|
| 4 个点同时推进 → 战线过长、质量下降 | 用户主动选择单点深入，AI 不主动"打包"多个点 |

| backlog 长期 pending → 文档腐烂 | 每次进入任一点深入时，更新本文档的"状态"字段 |
| 与已有 jtbd 分析重复 → 信息分散 | 本文档与 jtbd-thktree-analysis.md 互为索引，定期对照 |
