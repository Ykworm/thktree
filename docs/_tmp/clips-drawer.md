# 碎片库（Clips Drawer）— Brainstorming 草稿

> 日期：2026-07-08
> 模式：Freemode（代码直接在 dev 上改）
> 状态：方案已闭环，待用户确认后进入实现

## 1. 功能定位

全局文本暂存区，存术语、关键词、常用句式，在不同对话/场景里反复取用。

不是草稿箱，不是笔记——是**还没决定归属、但需要反复复用的文本碎片**。

## 2. 用户场景

- 讨论 A2UI 时，把"A2UI"存起来，在后续每个 sub chat 里反复取用
- 看到对话里一段有价值的描述，先摘出来存着，后面写笔记时可能用
- 存常用包名、命令、配置片段，省得每次重打

## 3. UIUX 方案

### 3.1 存入

- **入口**：长按选中文本 → 系统选区菜单追加"放入抽屉"按钮（与"复制""全选"并列）
- **来源**：对话消息文本
- **反馈**：存入后底部 sheet 末端短暂高亮新 item + 微振动（如果 sheet 当前是打开状态）；sheet 未打开时仅振动反馈

### 3.2 取出

- **入口**：对话输入框发送按钮左侧，加一个抽屉图标按钮（36x36 方块，与发送按钮风格统一）
- **不碰工具条**：工具条已有联网/深度思考/图片三个按钮，SE 上已顶死，不再加
- **交互**：点击 → 弹出底部 sheet → 列出所有碎片 → 点一条插入到输入框光标位置
- **sheet 行为**：点一条后 sheet **保持打开**，支持连续取多条
- **笔记编辑器不碰**：本次只在对话页做

### 3.3 长文本预览

- **触发**：长按 sheet 中的某个 item
- **预览区域**：弹出大尺寸 card（覆盖 sheet 大部分区域），显示更多内容
- **尺寸适配**：符合 iOS 规范，适配多种 iOS 设备屏幕尺寸
- **设计哲学**：预览区域尽量大，看不到的内容用户自行脑补——因为是用户自己放的，有印象。这种设计本身引导用户别放太长的东西
- **关闭**：点击预览区域外或关闭按钮
- **预览内无操作按钮**：长按 = 纯查看，不塞任何插入按钮。插入只通过直接点击 item 完成
- **手势职责分明**：长按 = 看，点击 = 用

### 3.4 碎片展示

- 短文本：全文显示
- 长文本：2-3 行截断，截断处用半透明白色 overlay 做 fade 效果，暗示"还有更多"
- 不搞标题/标签字段

## 4. 管理入口

- **位置**：sheet 本身顶部右侧"管理"文字按钮
- **进入后**：独立管理页
  - 列表形式展示所有碎片
  - 左滑删除（Dismissible）
  - 底部"清空全部"按钮（需二次确认）
- **不在 chat more 菜单和 settings 里放**——管理碎片时用户的第一直觉是"打开抽屉看看"

## 5. 数据规则

### 5.1 去重

- 同一文本内容已存在 → 不创建新条目
- 刷新该碎片的"放入时间"为当前时间 → 排序排到最前面
- 判重依据：文本内容完全一致（trim 后比较）

### 5.2 排序

- 按放入时间倒序（LIFO）：最近放入的排最前面
- 注意：去重时刷新放入时间 = "重新放入"

### 5.3 数量上限

- 最多 18 条
- 满了后继续添加 → 自动清理"放入时间最早"的条目（FIFO 淘汰）
- 不弹提示，静默清理

### 5.4 持久化

- 磁盘存储，App 重启后还在
- 全局作用域，不绑定 session/node
- 存储格式待定（JSON 文件 or SQLite），遵循 ThkTree 存储规范

## 6. 数据模型（初步）

```dart
class Clip {
  final String id;
  final String text;       // 碎片正文
  final DateTime createdAt; // 首次创建时间
  final DateTime putAt;    // 最近放入时间（去重时刷新，排序依据）
}
```

## 7. 技术要点

### 7.1 存入 — TextSelection 菜单扩展

Flutter 的 `EditableText` 选区菜单通过 `MaterialLocalizations` 控制。追加自定义按钮需要：
- 覆盖 `MaterialLocalizations` 或使用 `ContextMenuController` + `BrowserContextMenu`
- 或者自定义 `EditableText` 的 toolbar builder

### 7.2 取出 — ChatComposer 改动

- 在 ChatComposer 的发送按钮左侧插入抽屉按钮
- 输入框 Expanded 缩窄约 40pt
- 点击 → `showModalBottomSheet` 弹出碎片列表

### 7.3 预览 — 长按弹出

- `GestureDetector.onLongPress` → 弹出预览 card
- 预览 card 用 `showCupertinoModalPopup` 或自定义 `OverlayEntry`
- 需要处理 iOS 设备适配（safe area、不同屏幕高度）

### 7.4 管理 — 独立页面

- `Navigator.push` 到管理页
- `Dismissible` 实现左滑删除
- 批量清空需 `showCupertinoDialog` 二次确认

## 8. 验收方式

1. 编译通过 + diagnostics 无新增错误
2. 关键路径集成测试：
   - 存入：选中文本 → 菜单出现"放入抽屉" → 点击 → 碎片出现在列表
   - 取出：打开 sheet → 点一条 → 文本插入输入框光标位置
   - 去重：存入已存在文本 → 不新增，排到最前
   - 上限：存满 18 条后继续存 → 自动淘汰最早的
   - 预览：长按 item → 弹出纯预览（无插入按钮）→ 关闭后点 item 才插入
3. 手工验证：App 杀掉重启后碎片还在

## 9. 不做的事

- 不在 chat more 菜单和 settings 里放管理入口
- 不搞分类/标签/文件夹
- 不搞碎片搜索（18 条上限，滚动够了）
- 不做碎片编辑（只能删除后重新存）
