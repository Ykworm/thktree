# 大模型子页视觉回收与默认模型选择页方案

> 创建日期：2026-06-20
> 目标范围：`LlmProvidersScreen`、`DefaultModelConfigScreen`

## 背景

- `模型提供商` 和 `默认模型配置` 子页原本更接近卡片式设置页视觉。
- 将它们改成普通整页列表后，虽然削弱了顶部留白感，但视觉语言被改坏，页面显得不够大方。
- `默认模型配置` 当前使用 `CupertinoActionSheet` 选模型，层级和信息量都更适合独立页面，而不是 sheet。

## 决策

### 1. 视觉方向

- 保持 `inline title`，不使用 `large title`。
- 子页统一使用 `ThkFillCardPageBody`：NavBar 下方保留顶部留白，白色 pane 填满剩余 body。
- pane 内部使用连续列表项 + 分隔线，避免出现"上方一小块白卡 + 下方大片留白"。
- `模型提供商` 列表若没有可信品牌资产，不展示占位 icon。

### 2. 默认模型选择交互

- 不再使用 `CupertinoActionSheet` 选择模型。
- 点击 `聊天默认模型 / 标题生成模型 / 对话总结模型` 后，push 到新的模型选择页。
- 新页面按 provider 分组展示模型，并展示当前选中状态。
- 页面语义是单选 `option list`：未选中项不显示 chevron，仅当前选中项显示勾选。
- 用户点选模型后立即保存，并返回上一页。

## 预期结果

- 子页视觉回到更完整、更大方的设置页风格，同时填满 body。
- 默认模型选择链路改为：

```text
默认模型配置页 -> 模型选择页 -> 保存并返回
```

- 不再出现“sheet 承载深层选择”的违和感。
