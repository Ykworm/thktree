# 布局与色彩微调 (optimize-layout-details)

## 1. 哑光渐变风格的全局探索 (高级暖沙金)
- **缘起**：在优化搜索页横幅时，我们创造了一种“极其淡的暖金/米白渐变 (`0xFFFFFDF5` -> `0xFFF9F7F1`) + 高级哑光暖沙金 (`0xFFD4A373`)”的色彩组合。这种风格克制、中性且极具高级感。
- **全局推广**：我们决定将这种设计语言作为一种“强调与引导”的特定状态，推广到全局的其他组件中。
  1. **全局对话框 (ThkAlert)**：将 `CupertinoAlertDialog` 的默认按钮颜色（原本为系统蓝色）覆盖为我们的高级暖沙金。使得弹窗在保持原生 iOS 结构的同时，拥有了应用专属的高级调性。
  2. **全局空状态 (Empty State)**：以 `Wiki` 的空状态为例进行了重构。原本灰蒙蒙的图标被放置在一个带有哑光渐变底色和柔和暖金阴影的精致卡片中。下方的“生成”按钮也替换为了带有柔和光晕的暖沙金按钮。使得原本枯燥的“空状态”变成了一个精美的视觉引导点。

## 2. Lab 页的独立调性 (冷静科技灰)
- **背景**：在尝试了“暗色模式”和“纯白网格模式”后，用户反馈效果均不理想，尤其纯白网格显得过于生硬。我们需要一种能和“书房的暖纸色”区分开，但又不违和的高级感。
- **重新思考**：书房是“暖白 (`0xFFFAF9F6`)”，那么 Lab 应该是“**冷银灰 (`0xFFF2F4F7`)**”。
- **最终调整**：
  1. **背景变冷银灰**：去除了生硬的网格，将整个页面的底色改为极其干净、高级的科技银灰 `_kLabCoolBg`。这是一种非常有质感的“金属/科技”底色，与书房的“纸张”形成了完美的材质区分，且保持了全局的高明度。
  2. **原汁原味的顶图**：去除了所有破坏原图质感的“漂白滤镜”，让这张极其精美的英雄图恢复原本的色彩饱和度。底部通过渐变自然融入冷银灰背景，它现在是页面当之无愧的视觉中心。
  3. **高对比度的纯白卡片**：在冷灰色的背景上，纯白的卡片 (`0xFFFFFFFF`) 搭配极其克制的阴影（4% 透明度），显得异常干净、通透。去除了多余的蓝色边框，回归最纯粹的极简设计。

## 3. 移除多余的蓝光氛围，提升列表页通透感
- **背景**：`Themes`、`Notes` 和 `Search` 页面之前被添加了 `ThkPageAtmosphere`（产生顶部蓝光泄漏），这破坏了极简雅白风格的纯粹性，尤其在带有 `CupertinoSliverRefreshControl`（下拉刷新）的列表中，背景泄漏非常刺眼。
- **调整**：
  1. 彻底移除了 `Themes`、`Notes` 和 `Search` 页面的 `ThkPageAtmosphere` 包装，回归最纯净的 `AppColors.pageBg` (雅白) 页面底色。
  2. 恢复了 `Themes` 和 `Notes` 页面的 `CupertinoSliverRefreshControl`，在保证纯净视觉的同时，不破坏原有的下拉刷新交互功能。

## 4. Tree / Wiki 切换器的极致扁平化
- **背景**：原有的 `CupertinoSlidingSegmentedControl` 在雅白背景下显得沉重，且由于之前的错误 padding 包裹，导致滑块尺寸不一、不够扁平。
- **调整**：
  1. **完全自绘**：弃用系统控件，使用 `Row` + `Expanded` + `GestureDetector` 自绘了一个完全扁平、等比等宽的切换器。
  2. **视觉轻量**：外壳底色使用极其扁平的淡银灰 (`0xFFF2F4F7`)，没有任何阴影。激活状态的滑块变为纯白，并附带极其克制的 4% 投影。
  3. **文字对比**：选中态为深黑 `600` 字重，未选中态为淡灰 `400` 字重。整体犹如漂浮在雅白背景上的清透薄片，完美契合用户的审美期待。

## 5. 搜索框底色 (全局)
- 已完成：将所有搜索框底色改为纯白 (`0xFFFFFFFF`) 并增加轻微阴影，提升通透感。
