## 3. flutter_genui 关键事实校准

- **包名**：`genui`（pub.dev）/ `flutter/genui`（GitHub，labs.flutter.dev）
- **当前版本**：v0.9.2（2026-06-21 发布，3 天前）
- **状态标签**：**highly experimental**，API 会大幅变化
- **Flutter 要求**：>= 3.35.7
- **协议层**：A2UI v0.9（开源标准）
- **核心机制**：LLM 返回结构化 JSON（A2UI） → Flutter 从开发者提供的 widget catalog 渲染
- **LLM 接入**：任意能输出结构化 JSON 的 LLM（不绑定 Gemini；DeepSeek / OpenAI / Claude 都可走 A2UI 协议）
- **关键风险**：
  - v0.9.x 仍会剧烈变化，1.0 之前不适合生产
  - widget catalog 设计是真正的成本（不是"接入 genui"）
  - LLM 动态生成 UI 与"重思考者掌控一切"定位有哲学张力
- **未来 roadmap**（来自 GitHub）：Genkit 集成 / ADK 插件 / Streaming UI / Full-Screen Composition / A2A Agent / Dart Bytecode
