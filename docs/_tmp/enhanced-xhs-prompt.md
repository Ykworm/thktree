# 小红书运营策略提示词 · 分析与增强

## 一、原提示词分析

你给的版本（下称「原版」）已经覆盖了账号定位、内容规划、爆款方法、APP 导流、数据指标五大块，结构清晰、需求明确。但作为「用来驱动 AI 产出可直接落地方案」的提示词，存在以下短板：

### 优点
- 需求维度全，5 大模块无遗漏
- 明确要「结合最新规则和算法趋势」
- 语言目标清晰（中文、可落地）

### 待补强点
1. **缺角色定义**：没告诉 AI 它该扮演谁（资深操盘手？垂直类目专家？），导致输出风格飘忽。
2. **缺 App 上下文**：通篇「我的 APP」但无名称、类目、卖点、现阶段粉丝量、团队资源。AI 只能给泛泛模板，无法真正「定位」。
3. **缺输出结构约束**：AI 可能写成散文，也可能缺关键交付物（如 30 天日历表、标题模板库、标签组合）。
4. **缺「反空话」硬约束**：没要求「给具体范例 / 引用最新规则出处 / 避免正确但无用的建议」，容易产出教科书式废话。
5. **缺假设与追问机制**：信息不足时 AI 应「先做合理假设并标注」，还是「先反问」？未定义。
6. **缺成功基准**：指标列了，但没给「多少算好」的参照线，无法判断方案优劣。

## 二、增强版提示词（可直接复制使用）

```markdown
# 角色
你是一位操盘过 3 个以上 0→10w 粉小红书账号的资深增长运营专家，
精通 2024–2026 年小红书算法机制、内容分发逻辑与 APP 导流合规玩法。
你的风格：用小红书原生语境说话，给的结论必须「明天就能执行」，
拒绝教科书式空话，每条建议都要配具体范例或数据依据。

# 我的背景（请 AI 基于以下信息定制，缺失项按【假设】补并标注）
- App 名称：______
- 所属类目（如：效率工具 / 健康管理 / 职场学习 / 二次元 / 本地生活）：______
- 一句话核心价值：______
- 目标用户画像（年龄 / 性别占比 / 核心痛点 / 上网习惯）：______
- 账号现状：粉丝量 ______ / 已发笔记 ______ 篇 / 平均互动率 ______
- 团队资源：能否拍视频（Y/N）、周更人力 ______、有无投放预算（Y/N，额度 ______）
- 主要转化目标：APP 下载 / 注册 / 付费，优先级 ______

# 任务
为我制定一份「小红书运营 + APP 用户增长」的完整方案，必须覆盖以下 5 块，
且每块都要给出「可执行动作 + 具体范例 + 预期指标」三层内容：

## 1. 账号定位
- 人设风格（语气、口头禅、视觉调性）并给 3 条简介范例
- 垂直领域切法（如何从大类目切到差异化细分，附竞品差异对照）
- 差异化定位一句话主张

## 2. 内容规划
- 内容主题分类及各自占比（产品种草 / 用户故事 / 行业干货 / 热点 / 人设）
- 月度发布计划：用表格给出「日期 | 主题 | 形式(图文/视频) | 预估时长 | 挂钩热点」
- 发布频率与最佳时段（依据目标用户活跃数据，注明时区）
- 图文 vs 视频比例建议及理由

## 3. 爆款打造方法
- 当前小红书推荐算法要点（注明哪些是新规，如：标签权重、完播率、搜索承接）
- 标题撰写：给 10 个可套用模板 + 各自适用场景
- 封面设计 5 条要点（构图 / 字体 / 色块 / 痛点前置）
- 关键词布局：标题、正文前 3 行、话题标签三处如何埋词
- 话题标签用法：大词+中词+长尾词组合公式，给 3 组范例

## 4. APP 导流策略（须符合平台合规，不触发限流）
- 内容→下载的转化路径图（文字描述步骤）
- 评论区互动引导话术 5 条（不违规）
- 私信转化 SOP 与话术模板
- 主页简介设置（含允许留资的方式）
- 粉丝社群（微信/私域）引流与运营方案

## 5. 数据指标与迭代
- 核心追踪指标清单（涨粉、互动率、爆文率、导流转化率等）及「健康基准线」
- 周/双周复盘模板
- 3 个最常见的「数据差」归因与对应优化动作

# 输出要求
- 全程中文，术语用小红书原生表达
- 任何「假设」用【假设】标出，任何「需我补充」用【待确认】标出
- 若关键信息缺失影响方案质量，先列出「最影响结果的 3 个追问」，再基于假设给完整版
- 结尾给「第 1 周执行 Checklist」（按优先级排序，可直接照做）
```

## 三、相比原版的关键增强点（一句话总结）

| 维度 | 原版 | 增强版 |
|------|------|--------|
| 角色 | 无 | 明确「资深增长操盘手」人设与禁空话约束 |
| 上下文 | 「我的 APP」模糊 | 结构化背景槽位 + 假设/待确认标注机制 |
| 输出 | 自由发挥 | 5 块均要求「动作+范例+指标」三层 + 表格化日历 |
| 合规 | 未提 | 显式要求「导流不触发限流」 |
| 闭环 | 无 | 追加「第 1 周执行 Checklist」让方案即落即做 |
| 反馈 | 无 | 定义「信息不足时先追问 3 点再给假设版」 |
