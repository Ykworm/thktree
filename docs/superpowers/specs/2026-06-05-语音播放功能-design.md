# 语音播放功能设计

| 属性 | 说明 |
|------|------|
| 文档版本 | 1.0 |
| 更新日期 | 2026-06-05 |
| 平台 | iOS（Flutter） |
| 决策摘要 | 抽象层 + 插拔式 provider，MVP 用 Apple 原生 TTS |

## 1. 功能范围

### 1.1 MVP（本次实现）

| 能力 | 说明 |
|------|------|
| 单条消息播放 | 每条 assistant 消息底部新增播放按钮 |
| 播放控制 | 播放 / 停止，同一时间只有一条消息在播放 |
| 引擎 | iOS 原生 AVSpeechSynthesizer（离线、免费、中文音色好） |
| 语音选择 | 设置页可选择系统内置中文语音（Tingting 等）和语速 |
| 状态指示 | 按钮显示播放中 / 空闲状态 |

### 1.2 明确不做（v1 / MVP）

- 连续播放所有 assistant 消息
- 用户消息的语音播放
- 选中文字部分播放
- 后台播放
- Sherpa-ONNX / MiniMax 在线 TTS 接入
- 模型导入功能

### 1.3 后续版本预留

| 梯队 | 引擎 | 说明 |
|------|------|------|
| 第二梯队 | Sherpa-ONNX | 纯本地离线推理，可导入 .onnx 模型 |
| 第三梯队 | MiniMax / 阿里云 API | 在线高品质 + 音色克隆 |

## 2. 架构设计

### 2.1 整体分层

```
┌──────────────────────────────────────────────┐
│  MessageBubble（UI）                          │
│  └─ 播放按钮 + 状态绑定                       │
├──────────────────────────────────────────────┤
│  ttsControllerProvider（Riverpod State）      │
│  └─ 管理「谁在播放」和播放状态                 │
├──────────────────────────────────────────────┤
│  TtsService（抽象接口）                        │
│  └─ speak() / stop() / isSpeaking / voiceList  │
├──────────────────────────────────────────────┤
│  AppleTtsService（MVP 实现）                   │
│  └─ 通过 MethodChannel 调用 AVSpeechSynthesizer│
├──────────────────────────────────────────────┤
│  未来：SherpaOnnxTts / MiniMaxTts / ...       │
└──────────────────────────────────────────────┘
```

### 2.2 TtsService 抽象接口

```dart
abstract class TtsService {
  /// 播放文本，返回是否成功启动
  Future<bool> speak(String text);

  /// 停止当前播放
  Future<void> stop();

  /// 是否正在播放（Stream）
  Stream<bool> get isSpeaking;

  /// 可用语音列表
  Future<List<TtsVoice>> get availableVoices;

  /// 当前选中的语音 ID
  String? get currentVoiceId;

  /// 切换语音
  Future<void> setVoice(String voiceId);

  /// 语速 0.0 ~ 1.0
  double get rate;
  Future<void> setRate(double rate);

  /// 释放资源
  void dispose();
}

class TtsVoice {
  final String id;
  final String name;
  final String language; // "zh-CN"
  final String? quality; // "enhanced" / "premium"
}
```

### 2.3 AppleTtsService 实现方案

通过 Flutter MethodChannel 调用 iOS 原生 `AVSpeechSynthesizer`：

| iOS API | 用途 |
|---------|------|
| `AVSpeechSynthesizer` | 语音合成与播放 |
| `AVSpeechUtterance` | 单次播放任务（文本、语音、语速） |
| `AVSpeechSynthesisVoice` | 获取可用语音列表、按语言过滤 |
| `AVSpeechSynthesizerDelegate` | 播放开始/完成/暂停回调 |

**中文语音选择**：iOS 16+ 提供 `zh-CN-Tingting`（增强型）、`zh-CN-Pingting` 等高质量中文语音。

**MethodChannel 交互**：
- `speak(text, voiceId, rate)` → Dart 调用原生开始播放
- `stop()` → Dart 调用原生停止
- `onSpeechStateChanged` → 原生回调播放状态到 Dart

### 2.4 状态管理（Riverpod）

```dart
@riverpod
class TtsController extends _$TtsController {
  // 当前正在播放的消息 ID（null = 无人播放）
  String? playingMessageId;
  
  // 是否正在播放
  bool isSpeaking;
  
  // 执行播放
  Future<void> play(String messageId, String text);
  
  // 停止
  Future<void> stop();
  
  // 切换语音
  Future<void> setVoice(String voiceId);
}
```

**播放互斥规则**：
- 点击消息 A 的播放按钮 → 如有其他消息正在播放，先 stop 再播放 A
- 点击消息 A 的停止按钮 → 停止 A
- 消息 A 播放完毕 → 自动重置状态

### 3.1 MessageBubble 改动

在 assistant 消息底部操作栏中，复制按钮左侧新增播放按钮（纯 Cupertino 风格）：

```
┌────────────────────────────────────────────┐

│                                            │
│  [Markdown 正文]                           │
│                                            │
│  ▶️  📋  📤  🔄                            │
│  播放 复制 分享 重试                        │
```

播放按钮状态：

### 3.2 设置页改动

语音设置入口放在现有设置页中，新增 section：

| 设置项 | 类型 | 说明 |
|--------|------|------|
| 语音引擎 | 标签 | MVP 固定 "Apple 系统语音" |

| 语速 | 滑块 | 0.0 ~ 1.0，默认 0.5 |

## 4. 数据流

### 4.1 播放流程

```
用户点击播放按钮
  → TtsController.play(messageId, text)
  → 如果已有消息在播放 → AppleTtsService.stop()
  → AppleTtsService.speak(text)
  → iOS 原生开始播放
  → 状态更新: isSpeaking=true, playingMessageId=messageId
  → MessageBubble 重建，显示停止按钮

用户点击停止 / 播放完成
  → TtsController.stop()
  → AppleTtsService.stop()
  → 状态更新: isSpeaking=false, playingMessageId=null
  → MessageBubble 重建，恢复喇叭图标
```

### 4.2 语音切换流程

```
用户在设置页选择语音
  → TtsController.setVoice(voiceId)
  → AppleTtsService.setVoice(voiceId)
  → 持久化到 SharedPreferences
  → 后续播放使用新语音
```

## 5. 错误处理

| 场景 | 处理 |
|------|------|
| 文本为空 | 播放按钮不可见 |
| iOS TTS 初始化失败 | 播放按钮不可见，控制台 warn |
| 播放中切入电话 | AVSpeechSynthesizer 自动处理（iOS 系统行为） |
| 播放中切换页面 | 自动停止当前播放 |
| 无可用中文语音 | fallback 到默认系统语音，不阻塞功能 |
| streaming 中的消息 | 播放按钮隐藏 |

## 8. iOS 原生实现要点

```swift
// 核心职责：
// 1. 创建 AVSpeechSynthesizer 实例（单例）
```

## 10. 后续扩展指引

扩展新 TTS 引擎时只需：
1. 实现 `TtsService` 接口
2. 在 `app_services.dart` 中注册新 provider
3. 设置页增加引擎切换选项

已有动作按钮布局（复制、分享、播放、重试）为后续新增按钮预留了间距扩展空间。
