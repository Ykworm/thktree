# 文档拆分（Doc Split）实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 在 Theme 下实现 MD 文档导入 + LLM 自动 tree 拆分功能，用户可在 Chat 中与 LLM 讨论调整树结构，满意后物化为真实节点。

**架构：** 复用现有 Chat + Node 体系。用户通过 ThemeDetailScreen 菜单进入全屏编辑页粘贴 MD 文本，创建 chat 节点写入 MD 作为 user message（不触发 LLM）。用户在 Chat 中与 LLM 讨论树结构，满意后从右上角菜单提交，App 解析 LLM 输出的 Markdown 树并批量创建节点。

**技术栈：** Flutter/Dart, Riverpod, SQLite (node_store), 文件系统 (session.md)

```dart
// lib/data/services/tree_parser.dart

/// 解析 LLM 输出的 Markdown 树结构。
///
/// 支持的格式：
/// ```
/// - **标题A**
///   内容文本...
///   - **子标题A1**
///     子内容...
/// - **标题B**
///   内容文本...
/// ```
///
/// 返回扁平化的节点列表（按深度优先顺序），每个节点包含 title、content、depth。
/// children 列表为空——父子关系通过 depth 推断，在物化阶段构建。
class ParsedTreeNode {
  ParsedTreeNode({
    required this.title,
    required this.content,
    required this.depth,
  });

  final String title;
  final String content;
  final int depth;

  @override
  String toString() => 'ParsedTreeNode(depth=$depth, title=$title, content=${content.length}chars)';
}

/// 解析 Markdown 文本中的树结构。
///
/// 解析规则：
/// 1. 跳过 `## 维度X：...` 标题行（维度分隔标记）
/// 2. 匹配 `- **标题**` 模式作为节点，计算缩进深度
/// 3. 标题后的非加粗、非列表项文本作为该节点的 content
///
/// 返回解析后的节点列表（深度优先顺序）。
/// 如果无法解析到任何节点，返回空列表。
List<ParsedTreeNode> parseMarkdownTree(String markdown) {
  final lines = markdown.split('\n');
  final nodes = <ParsedTreeNode>[];

  String? currentTitle;
  int currentDepth = 0;
  final contentBuffer = StringBuffer();

  void flushNode() {
    if (currentTitle != null) {
      final content = contentBuffer.toString().trim();
      nodes.add(ParsedTreeNode(
        title: currentTitle!,
        content: content.isEmpty ? currentTitle! : content,
        depth: currentDepth,
      ));
    }
    currentTitle = null;
    contentBuffer.clear();
  }

  // 正则：匹配 `- **标题**` 或 `- **标题**` 后跟内容
  final nodePattern = RegExp(r'^(\s*)- \*\*(.+?)\*\*\s*$');
  // 正则：匹配 `- **标题** 内容`（同行）
  final nodeWithContentPattern = RegExp(r'^(\s*)- \*\*(.+?)\*\*\s+(.+)$');
  // 正则：匹配 `## 维度` 标题（跳过）
  final dimensionPattern = RegExp(r'^##\s+维度');
  // 正则：匹配 `---` 分隔线（跳过）
  final separatorPattern = RegExp(r'^---\s*$');

  for (final line in lines) {
    // 跳过维度标题和分隔线
    if (dimensionPattern.hasMatch(line) || separatorPattern.hasMatch(line)) {
      continue;
    }

    // 匹配 `- **标题**` （标题独占一行）
    final nodeMatch = nodePattern.firstMatch(line);
    if (nodeMatch != null) {
      flushNode();
      final indent = nodeMatch.group(1)!;
      currentTitle = nodeMatch.group(2)!.trim();
      currentDepth = (indent.length / 2).floor();
      continue;
    }

    // 匹配 `- **标题** 内容` （标题和内容同行）
    final nodeWithContentMatch = nodeWithContentPattern.firstMatch(line);
    if (nodeWithContentMatch != null) {
      flushNode();
      final indent = nodeWithContentMatch.group(1)!;
      currentTitle = nodeWithContentMatch.group(2)!.trim();
      currentDepth = (indent.length / 2).floor();
      contentBuffer.writeln(nodeWithContentMatch.group(3)!.trim());
      continue;
    }

    // 非标题行 → 作为当前节点的 content
    if (currentTitle != null && line.trim().isNotEmpty) {
      contentBuffer.writeln(line.trim());
    }
  }

  flushNode();
  return nodes;
}
```

```dart
// lib/data/services/doc_split_service.dart

import 'dart:io';

import 'package:thk_tree/data/services/session_markdown.dart';
import 'package:thk_tree/data/services/tree_parser.dart';
import 'package:thk_tree/data/stores/node_store.dart';
import 'package:thk_tree/data/stores/session_store.dart';

/// 将 LLM 输出的 Markdown 树结构物化为 theme 下的真实节点。
///
/// 流程：
/// 1. 从 docSplitNode 的 session.md 读取最后一条 assistant 消息
/// 2. TreeParser 解析 → List<ParsedTreeNode>
/// 3. 深度优先遍历创建节点 + 写入 content 为 user message
/// 4. 删除 docSplit 预览节点
class DocSplitService {
  DocSplitService({
    required this.nodeStore,
    required this.sessionStore,
  });

  final NodeStore nodeStore;
  final SessionStore sessionStore;

  /// 物化树结构。
  ///
  /// [docSplitNodeId] — 用于讨论树结构的预览 chat 节点 ID。
  /// [themeId] — 目标 theme。
  /// [themePath] — theme 的磁盘路径。
  /// [sourceMdText] — 用户最初粘贴的 MD 文本（用于 sourceExcerpt）。
  ///
  /// 返回创建的节点数量。如果解析失败返回 0。
  Future<int> materializeTree({
    required String docSplitNodeId,
    required String themeId,
    required String themePath,
    required String sourceMdText,
  }) async {
    // 1. 读取最后一条 assistant 消息
    final doc = await sessionStore.readSession(docSplitNodeId);
    String? lastAssistantBody;
    for (final msg in doc.messages.reversed) {
      if (msg.role == SessionRole.assistant &&
          msg.status == SessionMessageStatus.done &&
          msg.body.trim().isNotEmpty) {
        lastAssistantBody = msg.body;
        break;
      }
    }
    if (lastAssistantBody == null) {
      return 0; // 无 assistant 消息
    }

    // 2. 解析树结构
    final flatNodes = parseMarkdownTree(lastAssistantBody);
    if (flatNodes.isEmpty) {
      return 0; // 解析失败
    }

    // 3. 深度优先遍历创建节点
    // 维护一个栈：(depth, nodeId)，用于推断 parentId
    final stack = <(int depth, String nodeId)>[];
    int createdCount = 0;

    final sourceExcerpt = sourceMdText.length <= 80
        ? sourceMdText
        : '${sourceMdText.substring(0, 80)}...';

    for (final parsed in flatNodes) {
      // 弹出栈中 depth >= 当前 depth 的项（它们不是当前节点的父节点）
      while (stack.isNotEmpty && stack.last.$1 >= parsed.depth) {
        stack.removeLast();
      }

      // parentId = 栈顶的 nodeId（如果栈非空且 depth 更小）
      final String? parentId =
          stack.isNotEmpty && stack.last.$1 < parsed.depth
              ? stack.last.$2
              : null;

      // 创建节点
      final childNode = await nodeStore.createChatNode(
        themeId: themeId,
        themePath: themePath,
        parentId: parentId,
        title: parsed.title,
      );

      // 写入 content 作为 user message
      await sessionStore.appendUserMessage(
        nodeId: childNode.nodeId,
        content: parsed.content,
      );

      // 记录来源
      await nodeStore.updateNodeSourceInfo(
        nodeId: childNode.nodeId,
        sourceExcerpt: sourceExcerpt,
        sourceType: 'docSplit',
      );

      // 压栈
      stack.add((parsed.depth, childNode.nodeId));
      createdCount++;
    }

    // 4. 删除 docSplit 预览节点
    await nodeStore.deleteNodeSubtree(nodeId: docSplitNodeId);

    return createdCount;
  }
}
```

Future<void> _onImportDocSplit(BuildContext context, WidgetRef ref) async {
  final l10n = AppLocalizations.of(context)!;

  // 1. 打开全屏编辑页
  final mdText = await Navigator.of(context).push<String>(
    CupertinoPageRoute(
      builder: (_) => const DocSplitInputScreen(),
    ),
  );
  if (mdText == null || mdText.trim().isEmpty) return;
  if (!context.mounted) return;

  try {
    // 2. 获取 store 和 theme 信息
    final container = ProviderScope.containerOf(context, listen: false);
    final nodeStore = await container.read(nodeStoreProvider.future);
    final sessionStore = await container.read(sessionStoreProvider.future);
    final detailState = ref.read(themeDetailControllerProvider(widget.themeId)).value;
    if (detailState == null) return;

    // 3. 创建 docSplit 预览节点
    final previewNode = await nodeStore.createChatNode(
      themeId: widget.themeId,
      themePath: detailState.themePath,
      parentId: null,  // 作为根节点
      title: l10n.docSplitInputTitle,
    );

    // 4. 写入 MD 文本为 user message（不触发 LLM 回复）
    await sessionStore.appendUserMessage(
      nodeId: previewNode.nodeId,
      content: mdText,
    );

    // 5. 记录来源
    final sourceExcerpt = mdText.length <= 80
        ? mdText
        : '${mdText.substring(0, 80)}...';
    await nodeStore.updateNodeSourceInfo(
      nodeId: previewNode.nodeId,
      sourceExcerpt: sourceExcerpt,
      sourceType: 'docSplit',
    );

    if (!context.mounted) return;

    // 6. 跳转 ChatScreen（不触发 LLM 回复）
    context.push(
      '/themes/${widget.themeId}/nodes/${previewNode.nodeId}',
      extra: ChatScreenLaunchParams(
        title: l10n.docSplitInputTitle,
        autoTriggerReply: false,
        isDocSplit: true,
      ),
    );

    // 7. 刷新主题树
    unawaited(
      ref.read(themeDetailControllerProvider(widget.themeId).notifier)
          .refresh()
          .catchError((_) {}),
    );
  } catch (e) {
    if (!context.mounted) return;
    ThkAlert.show(context: context, message: e.toString());
  }
}
```

- [ ] **步骤 5：实现 `_onSubmitDocSplit` 方法**

```dart
Future<void> _onSubmitDocSplit(BuildContext context) async {
  final l10n = AppLocalizations.of(context)!;
  try {
    final container = ProviderScope.containerOf(context, listen: false);
    final nodeStore = await container.read(nodeStoreProvider.future);
    final sessionStore = await container.read(sessionStoreProvider.future);

    // 读取原始 MD 文本（第一条 user message）
    final doc = await sessionStore.readSession(widget.nodeId);
    String sourceMdText = '';
    for (final msg in doc.messages) {
      if (msg.role == SessionRole.user) {
        sourceMdText = msg.body;
        break;
      }
    }

    // 创建 DocSplitService 并执行物化
    final service = DocSplitService(
      nodeStore: nodeStore,
      sessionStore: sessionStore,
    );
    final createdCount = await service.materializeTree(
      docSplitNodeId: widget.nodeId,
      themeId: widget.themeId,
      themePath: (await nodeStore.getThemeRow(themeId: widget.themeId))['themePath'] as String,
      sourceMdText: sourceMdText,
    );

    if (!context.mounted) return;

    if (createdCount == 0) {
      ThkAlert.show(context: context, message: l10n.docSplitParsingFailed);
      return;
    }

    // 刷新主题树
    unawaited(
      container.read(themeDetailControllerProvider(widget.themeId).notifier)
          .refresh()
          .catchError((_) {}),
    );

    // 返回 ThemeDetailScreen
    ThkAlert.show(context: context, message: l10n.docSplitSuccess(createdCount));
    context.go('/themes/${widget.themeId}/tree');
  } catch (e) {
    if (!context.mounted) return;
    ThkAlert.show(context: context, message: e.toString());
  }
}
```
