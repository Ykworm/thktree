# 语音播放功能设计

| 属性 | 说明 |
|------|------|
| 文档版本 | 1.1 |
| 更新日期 | 2026-06-17 |
| 平台 | iOS（Flutter） |
| 决策摘要 | 抽象层 + 插拔式 provider，MVP 用 Apple 原生 TTS；播放器独立页面，语速不持久化 |

---

## 1. 功能范围

### 1.1 MVP（本次实现）

| 能力 | 说明 |
|------|------|
| 单条消息播放 | 每条 assistant 消息底部新增播放按钮，点击打开播放器页面 |
| 播放控制 | 播放器页面内播放 / 停止，同一时间只有一条消息在播放 |
| 引擎 | iOS 原生 AVSpeechSynthesizer（离线、免费、中文音色好） |
| 语音选择 | 独立 TTS 设置页可选择系统内置中文声线（人物） |
| 语速调节 | 播放器页面内实时调节，每次打开默认正常语速 |
| 状态指示 | 播放器页面显示播放状态，MessageBubble 按钮显示播放中 / 空闲 |

### 1.2 明确不做（v1 / MVP）

- 连续播放所有 assistant 消息
- 用户消息的语音播放
- 选中文字部分播放
- 后台播放
- 语速默认值持久化（每次打开播放器都是正常语速）
- Sherpa-ONNX / MiniMax 在线 TTS 接入
- 模型导入功能

### 1.3 后续版本预留

| 梯队 | 引擎 | 说明 |
|------|------|------|
| 第二梯队 | Sherpa-ONNX | 纯本地离线推理，可导入 .onnx 模型 |
| 第三梯队 | MiniMax / 阿里云 API | 在线高品质 + 音色克隆 |

### 2.2 TtsService 抽象接口

```dart
abstract class TtsService {
  /// 播放文本，返回是否成功启动
  Future<bool> speak(String text, {double? rate});

  /// 停止当前播放
  Future<void> stop();

  /// 是否正在播放（Stream）
  Stream<bool> get isSpeaking;

  /// 可用语音列表
  Future<List<TtsVoice>> get availableVoices;

  /// 当前选中的语音 ID
  String? get currentVoiceId;

  /// 切换语音
  Future<void> setVoice(String voiceId);

  /// 释放资源
  void dispose();
}

class TtsVoice {
  final String id;
  final String name;
  final String language; // "zh-CN"
  final String? quality; // "enhanced" / "premium"
}
```

### 2.3 AppleTtsService 实现方案

通过 Flutter MethodChannel 调用 iOS 原生 `AVSpeechSynthesizer`：

| iOS API | 用途 |
|---------|------|
| `AVSpeechSynthesizer` | 语音合成与播放 |
| `AVSpeechUtterance` | 单次播放任务（文本、语音、语速） |
| `AVSpeechSynthesisVoice` | 获取可用语音列表、按语言过滤 |
| `AVSpeechSynthesizerDelegate` | 播放开始/完成/暂停回调 |

**中文声线选择**：iOS 提供多个中文声线（人物），如 `zh-CN-Tingting`（婷婷）、`zh-CN-Pingting`（萍婷）、`zh-CN-Shanshan`（姗姗）等。每个声线有独立的音色特征。

**MethodChannel 交互**：
- `speak(text, voiceId, rate)` → Dart 调用原生开始播放
- `stop()` → Dart 调用原生停止
- `getVoices()` → 获取可用语音列表
- `onSpeechStateChanged` → 原生回调播放状态到 Dart

### 2.4 状态管理（Riverpod）

```dart
@riverpod
class TtsController extends _$TtsController {
  // 当前正在播放的消息 ID（null = 无人播放）
  String? playingMessageId;
  
  // 是否正在播放
  bool isSpeaking;
  
  // 执行播放（rate 为即时传入，不持久化）
  Future<void> play(String messageId, String text, {double rate = 0.5});
  
  // 停止
  Future<void> stop();
  
  // 切换语音（持久化）
  Future<void> setVoice(String voiceId);
}
```

**播放互斥规则**：
- 点击消息 A 的播放按钮 → 如有其他消息正在播放，先 stop 再播放 A
- 在播放器页面点击停止 → 停止当前播放
- 消息 A 播放完毕 → 自动重置状态
- 播放器页面关闭 → 不自动停止（允许后台播放，但受 iOS 系统限制）

|------|------|------|

## 4. 数据流

### 4.1 播放流程

```
用户点击 MessageBubble 播放按钮
  → 打开 TtsPlayerScreen(messageId, text)
  → 用户点击播放按钮
  → TtsController.play(messageId, text, rate: 当前滑块值)
  → 如果已有消息在播放 → AppleTtsService.stop()
  → AppleTtsService.speak(text, voiceId, rate)
  → iOS 原生开始播放
  → 状态更新: isSpeaking=true, playingMessageId=messageId
  → 播放器页面按钮变为"停止"

用户点击停止 / 播放完成
  → TtsController.stop()
  → AppleTtsService.stop()
  → 状态更新: isSpeaking=false, playingMessageId=null
  → 播放器页面按钮变为"播放"
```

### 4.2 语音切换流程

```
用户在 TtsSettingsScreen 选择声线
  → TtsController.setVoice(voiceId)
  → AppleTtsService.setVoice(voiceId)
  → 持久化到 SharedPreferences
  → 播放示例语音试听
  → 后续播放使用新声线
```

## 5. 错误处理

| 场景 | 处理 |
|------|------|
| 文本为空 | 播放按钮不可见 |
| iOS TTS 初始化失败 | 播放按钮不可见，控制台 warn |
| 播放中切入电话 | AVSpeechSynthesizer 自动处理（iOS 系统行为） |
| 播放中切换页面 | 播放器页面关闭不自动停止（iOS 系统管理） |
| 无可用中文声线 | fallback 到默认系统语音，不阻塞功能 |
| streaming 中的消息 | 播放按钮隐藏 |
| 语速值异常 | 自动 clamp 到 0.0~1.0 范围 |

## 8. iOS 原生实现要点

### 8.1 TtsPlugin.swift

```swift
// 核心职责：
// 1. 创建 AVSpeechSynthesizer 实例（单例）
// 2. 接收 Flutter 的 speak/stop/getVoices 调用
// 3. 通过 FlutterMethodChannel 回调播放状态
// 4. 管理 AVSpeechSynthesisVoice 列表，按语言过滤
// 5. 支持 rate 参数（0.0~1.0）
```

> 详细实现说明（Xcode 注册、iOS 版本兼容性、Channel 协议）见：[iOS 原生 TTS 桥接实现](2026-06-17-iOS原生TTS桥接实现.md)

### 8.2 AppDelegate 注册

在 `AppDelegate.swift` 中注册 `TtsPlugin` 的 MethodChannel。

### 8.3 无需 Info.plist 权限

`AVSpeechSynthesizer` 不需要麦克风或其他特殊权限。

## 10. 后续扩展指引

扩展新 TTS 引擎时只需：
1. 实现 `TtsService` 接口
2. 在 `app_services.dart` 中注册新 provider
3. 设置页增加引擎切换选项
4. 播放器页面适配新引擎的语速范围（如有不同）

已有动作按钮布局（复制、分享、播放、重试）为后续新增按钮预留了间距扩展空间。
