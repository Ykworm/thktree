## 2. 核心实现要点

### 2.1 自定义插件的 Xcode 注册要求

`TtsPlugin.swift` 是**手动创建的原生插件**（非 pubspec.yaml 引入的 Flutter package），必须显式加入 Xcode 项目的 `project.pbxproj` 四个位置：

1. `PBXBuildFile` — 声明编译动作
2. `PBXFileReference` — 声明文件引用
3. `PBXGroup` — 将文件加入 Runner 组
4. `PBXSourcesBuildPhase` — 加入编译源文件列表

**常见错误**：仅创建 `.swift` 文件但未加入 `project.pbxproj`，编译时报 `Cannot find 'TtsPlugin' in scope`。

### 2.2 iOS 版本兼容性

`AVSpeechSynthesisVoice.Quality` 枚举的 `.premium` 仅在 **iOS 16.0+** 可用。项目 Deployment Target 低于 16.0 时，需使用运行时版本检查：

```swift
if #available(iOS 16.0, *) {
    // 可访问 .premium
} else {
    // 仅 .default / .enhanced
}
```

`getVoices()` 返回的 `quality` 字段三档映射：
- iOS 16+：`premium` / `enhanced` / `default`
- iOS 15 及以下：`enhanced` / `default`

## 3. Channel 协议

| Channel | 类型 | 方法/事件 | 参数 | 返回值 |
|---------|------|-----------|------|--------|
| `thktree/tts` | MethodChannel | `speak` | `{ text: String, voiceId: String?, rate: Double? }` | `Bool` |
| `thktree/tts` | MethodChannel | `stop` | `null` | `Void` |
| `thktree/tts` | MethodChannel | `getVoices` | `null` | `[[String: String]]` |
| `thktree/tts/events` | EventChannel | `onListen` | — | `Bool`（true=开始, false=结束） |
