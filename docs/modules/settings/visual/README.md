## 1. SettingsScreen 布局

```dart
CupertinoPageScaffold(
  navigationBar: ThkNavBar.inline(title: l10n.settings),
  child: SafeArea(
    child: ListView(
      children: [
        ThkListSection(...),  // 外观
        ThkListSection(...),  // 语言
        ThkListSection(...),  // 语音播放
        ThkListSection(...),  // LLM
        ThkListSection(...),  // 数据
        ThkListSection(...),  // 关于
        ThkListSection(...),  // 调试（仅 kDebugMode）
      ],
    ),
  ),
)
```

## 2. Section 顺序（固定，不可重排）

| 顺序 | Section | 包含项 |
|------|---------|--------|
| 1 | 外观 | 主题模式、字体大小、节点配色方案 |
| 2 | 语言 | i18n 切换（中/英） |
| 3 | 语音播放 | 语音引擎、朗读语音选择、语速滑块 |
| 4 | 大模型 | 跳转到"大模型"入口页，再进入"模型提供商"和"默认模型配置" |
| 5 | 数据 | 导出、清空缓存（destructive）、修复索引 |
| 6 | 关于 | 版本号、开源许可、隐私政策 |
| 7 | 调试 | SQLite 大小、强制重索引、日志级别（仅 kDebugMode） |

## 3. TTS 设置项

| 设置项 | 类型 | 值 |
|--------|------|-----|
| 语音引擎 | 标签 | MVP 固定 "Apple 系统语音" (`l10n.ttsAppleSystem`) |
| 朗读语音 | 选择器 | 列出系统中文语音（Tingting 等），点击试听 |
| 语速 | 不持久化 | 在播放器页以 speed preset 循环切换（0.75× / 1× / 1.5× / 2×），默认 0.75×（rate=0.35） |

## 4. TTS 播放器全屏页（TtsPlayerScreen）

### 4.1 层级结构

```
┌─────────────────────────────────────────────────────┐
│  NavBar: ThkNavBar.inline                           │
│          title: "朗读"                               │
│          onTitleDoubleTap: 滚动到顶部                  │
│          trailing: ⚙ 语音设置入口                      │
├─────────────────────────────────────────────────────┤
│                                                      │
│  ┌─ Stack Layer 1: 3 层背景 ──────────────────────┐ │
│  │  TtsPlayerBackground (gradient + glow)         │ │
│  └─────────────────────────────────────────────────┘ │
│                                                      │
│  ┌─ Stack Layer 2: 文本区（铺满全屏）────────────┐ │
│  │  GptMarkdown 渲染 Markdown 内容                 │ │
│  │  SingleChildScrollView                         │ │
│  │  bottom padding: 120dp（防控制面板遮挡）          │ │
│  │  内容可延伸到屏幕底部，透过毛玻璃可见             │ │
│  └─────────────────────────────────────────────────┘ │
│                                                      │
│  ┌─ Stack Layer 3: 毛玻璃控制面板（Positioned）──┐ │
│  │  BackdropFilter blur(sigma: 20)                │ │
│  │  Container(alpha: 0.65) — 半透明，文字模糊透出   │ │
│  │  ┌──────────────────────────────────────────┐  │ │
│  │  │ [▶ 播放按钮 44dp]            [0.75× 速度] │  │ │
│  │  │  TtsPulseRings 扩散环（播放中）            │  │ │
│  │  └──────────────────────────────────────────┘  │ │
│  │  底部 home indicator 安全区 34dp                │ │
│  └─────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────┘
```

### 4.2 交互行为

| 交互 | 效果 |
|------|------|
| 双击导航栏标题 "朗读" | 平滑滚动到顶部（300ms easeOut） |
| 点击播放按钮 | 开始/停止朗读 |
| 点击速度标签 | 循环切换 0.75× → 1× → 1.5× → 2× |
| 滚动文本区 | 内容自然延伸到毛玻璃后面 |

### 4.3 播放按钮状态

| 状态 | 图标 | 颜色 | 动效 |
|------|------|------|------|
| 空闲 | `AppIcons.ttsPlay`（`sf_play_fill`，三角形） | surface + border | 无 |
| 播放中 | `AppIcons.ttsPause`（`sf_pause_fill`，两竖） | accent | TtsPulseRings 扩散环 |

### 4.4 控制面板尺寸

| Token | 值 | 说明 |
|-------|-----|------|
| `playerButtonSize` | 40dp | 圆形按钮直径 |
| `playerButtonIconSize` | 18dp | 图标尺寸 |
| `controlPanelHeight` | 68dp | mini bar 总高（40 button + 14 top + 14 bottom = 68）|
| `controlPanelBlurSigma` | 20.0 | 毛玻璃模糊强度 |
| `controlPanelPaddingH` | 20dp | 水平内边距 |
| `controlPanelPaddingV` | 14dp | 垂直内边距（顶/底对称，按钮居中）|
| `controlPanelSurfaceAlpha` | 0.35 | 毛玻璃表面 alpha（更透，背景渐变可见）|
| `controlPanelRadius` | 20dp | mini bar 顶部圆角（iOS standard）|

- **清空本地缓存**：`isDestructiveAction: true`，二次确认
- **删除数据**：带 destructive 警示

## 6. 大模型子页

### 6.1 导航层级

```text
设置页 -> 大模型 -> 模型提供商
             └-> 默认模型配置 -> 模型选择页
```

### 6.2 大模型入口页

- `inline title`，不使用 `large title`
- NavBar 下方保留一段顶部留白
- 主体是接管剩余 body 的整块白色 pane，而不是按内容高度收缩的小卡片
- pane 内部使用连续列表项 + 细分隔线，承接"模型提供商"与"默认模型配置"两个入口

### 6.3 默认模型配置页

- 延续大模型入口页的 pane 式布局
- 只展示 3 个设置项：聊天默认模型 / 标题生成模型 / 对话总结模型
- subtitle 显示 `提供商名 · 模型名`；未设置时显示 `未设置`
- 点击任一设置项后 push 到独立模型选择页，不使用 `CupertinoActionSheet`

### 6.4 模型选择页

- 按 provider 分组展示模型，分组标题使用小号灰字
- 页面语义是单选 `option list`，未选中项不显示 chevron
- 仅当前选中项在右侧显示勾选图标
- 点选后立即保存，并返回上一页

### 6.5 模型提供商页

- 同样使用 pane 式布局填满剩余 body，避免列表下方大片留白
- 第一个列表项与 nav bar 之间保留明确顶部距离，符合 iOS 设置页节奏
- 若没有可信的厂商 logo，不展示占位 icon；列表项只保留标题、副标题与 chevron
- subtitle 展示当前已配置模型数量，无模型时显示"暂无模型"
