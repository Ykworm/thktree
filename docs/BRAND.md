## 2. 品牌基础（Brand Foundation）

### 2.1 Purpose（为什么存在）

让人机协作地构建"长在自己身上的"结构化知识体系——像树一样有机生长，而不是被信息洪流淹没。

### 2.2 Vision（想去哪）

成为 AI-native 时代个人知识操作系统的标杆，让"思考有结构"成为默认体验。

### 2.3 Mission（做什么）

为深度思考者提供一棵可生长、可检索、可对话的知识树；隐私优先、本地优先、人机协作。

### 2.4 Values（价值观，指导一切行为）

1. **有机生长（Organic）** — 知识如树，结构化但不僵化。表现为：支持嵌套、分支、实验，不强迫单一结构。
2. **克制有序（Restraint & Order）** — 少即是多，层级即清晰。表现为：留白、中性底座、靠字号而非颜色做层级。
3. **实验包容（Experimental）** — 鼓励试错，Lab 精神。表现为：Lab 功能、开放"为什么这么设计"的复盘。
4. **人文温度（Humanist）** — 理性之外有温度。表现为：隐私尊重、技术服务于人、不冷冰冰。

### 2.5 Personality（人格，5 个特质）

- **克制（Restrained）**：不过度设计，话不多但句句到位。
- **有序（Orderly）**：逻辑严谨，先结论后展开。
- **实验性（Experimental）**：好奇、敢试，乐于分享取舍。
- **人文（Humanist）**：温暖、成熟、有温度。
- **理性（Rational）**：冷静、专业、可信赖。

> 一句话概括：一个"安静但可靠的建筑师"。

### 2.6 Brand Promise（对用户的承诺）

你的知识，始终属于你；你的结构，始终清晰；你的工具，始终克制。

## 3. 品牌声音（Brand Voice）

### 3.1 Voice 特征（三件套）

- **克制但有人味**：不堆术语、不喊口号，像靠谱的朋友在讲解。
- **结构清晰**：先结论后展开，用层级而非喧哗表达。
- **实验精神**：坦诚"为什么这么设计"，分享取舍与踩坑。

### 3.2 Tone 变体（按场景切换）

| 场景 | 语气 | 示例 |
|------|------|------|
| 产品内 UI 文案 | 安静、引导式、最少文字 | "已保存到知识树" |
| 对外（博客 / 社媒） | 坦诚、有观点、一点工程师幽默 | "我把对话组织成了一棵树，脑子终于不乱了" |
| 危机 / 公告 | 透明、负责、行动导向 | "我们已知 X 问题，正在修复，预计 Y 前上线" |

### 3.3 文案原则（Do / Don't）

- ✅ 用具体动词（保存 / 生长 / 检索 / 对话）
- ✅ 长句拆短，靠层级而非加粗喧哗
- ✅ 提及"你的"知识，强调归属与隐私
- ❌ 不用"赋能""闭环""颠覆"等空话
- ❌ 不用全大写喊叫、不过度使用感叹号
- ❌ 不贬低竞品，只讲自己的差异

### 3.4 UI 文案前后对比示例

- ❌ 错误："Operation Failed! Please try again later!!!"
- ✅ 正确："没能保存，再试一次"
- ❌ 错误："Intelligent AI-powered knowledge base solution"
- ✅ 正确："一棵能对话、能检索、本地生长的知识树"

## 4. 信息架构（Messaging Architecture）

### 4.1 Tagline（选其一，全渠道统一）

- **主推 A：「让思考，长成一棵树。」**（推荐，呼应知识树隐喻）
- 备选 B：「你的知识，有机生长。」

### 4.2 Value Proposition

本地优先、隐私安全的 AI 知识树——把对话、笔记、主题长成同一棵结构化的树。

### 4.3 Key Messages（按受众）

1. **思考者**：结构化不是束缚，是让复杂变清晰。
2. **隐私敏感者**：数据在本地，模型你自选。
3. **开发者 / 同行**：一个独立开发者的完整产品方法论。

### 4.4 命名规范（强制）

- 唯一写法：**ThkTree**（大驼峰，无空格、无下划线）。
- 禁止：`thk_tree` / `thktree` / `Thk Tree` / `THKTREE`。
- 商店 / 官网 / GitHub / 社媒简介 / 代码包名展示层，全部对齐为 ThkTree。
- 个人品牌署名：Yk酱。

### 4.5 标准简介（Boilerplate）

- **产品（≤60 字）**：ThkTree 是一款 iOS 优先的 AI 知识树 App，把 LLM 对话组织成可嵌套、可检索、本地生长的树，隐私优先、模型自选。
- **个人（Yk酱，≤80 字）**：Yk酱，独立开发者，ThkTree 的作者。专注 AI-native 知识管理，相信"结构化思考"能让人更清醒地驾驭信息。

## 6. 品牌保护（Basics）

- **命名**：全渠道锁定 ThkTree；注册相关域名（如 thktree.app）。
- **商标**：至少申请 App 名 "ThkTree" + Logo（同心圆环树形）文字 / 图形商标。
- **监测**：定期搜 Yk酱 / ThkTree，发现未授权使用或仿冒及时处置。
- **代码侧**：禁止硬编码 `CupertinoColors.system*`，一律走 `AppColors` 语义 token（已有 war-story 教训，参见图片清理页配色修复记录）。
