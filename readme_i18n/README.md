# readme_i18n

多语言 README 目录。根目录 [`README.md`](../README.md) 为 GitHub 默认展示（简体中文）。

| 文件 | 语言 |
|------|------|
| [`README_zh_CN.md`](README_zh_CN.md) | 简体中文 |
| [`README_en_US.md`](README_en_US.md) | English |

命名约定：`README_{locale}.md`，与 Immich 等开源项目一致。

维护约定：

- 更新产品介绍时，同步修改根目录 `README.md` 与对应语言文件
- 视觉素材路径统一使用 `../assets/readme/`（SVG）与 `../screenshots/`（截图）
